# Paladin

### An orbital edge-compute facility under fire, five agents keeping it alive

**Project PALADIN is an interactive 2D portfolio application simulating PALADIN-Station, an orbital edge-compute facility. When a solar flare, a micrometeoroid puncture, or a cooling breach strikes, five autonomous engineering agents diagnose and fix it live, on a retro sci-fi tactical console, with every fix formally checked before it's applied.**

## About

PALADIN-Station is rendered as a zoomable, pannable 2D tactical telemetry grid (the Console), tracking power buses, servers, and thermal vectors. Alongside it, the Operations Deck streams the activity of five agents as they manage an emergency:

- **ORION** — Command Orchestrator
- **VULCAN** — Thermal & Fluids Governor
- **TESLA** — Electrical Grid Overseer
- **MERCURY** — Workload & Network Router
- **ATHENA** — Deterministic Trust & Verification Engine

No fix reaches the station without first passing Athena's validation handshake: a deterministic, zero-hallucination check that it won't cause a secondary blackout.

See `CONTEXT.md` for the full domain model and `docs/architecture/ARCHITECTURE.md` for the system design.
